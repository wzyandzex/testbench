# SWE 任务场景

## 概述

SWE（SWE-bench）任务是基于真实 GitHub Issue 的代码修复任务，是系统的高级评测功能。

---

## 用户故事

### 作为开发者，我希望能够基于 GitHub Issue 创建 SWE 修复任务

**前置条件**：
- 已登录系统
- 已选择组织

**操作步骤**：
1. 导航到「SWE 任务」页面
2. 点击「创建任务」按钮
3. 输入 GitHub 仓库 URL
4. 填写 Issue 信息（标题、内容）
5. 配置测试策略（full/smart/skip）
6. 是否启用自动修复
7. 点击「创建」

**预期结果**：
- 任务创建成功，显示任务 ID
- 自动跳转到任务详情页
- WebSocket 开始推送进度

---

### 作为开发者，我希望实时查看 SWE 任务执行进度

**前置条件**：
- SWE 任务已创建

**操作步骤**：
1. 在任务详情页查看进度条
2. 查看当前执行阶段
3. 实时查看执行日志

**预期结果**：
- 进度条实时更新
- 阶段指示器显示当前阶段
- 日志区域显示最新输出

**执行阶段**：
1. **init** - 任务初始化
2. **repository** - 克隆仓库
3. **indexing** - 构建 issue 索引
4. **executing** - Agent 执行修复
5. **testing** - 运行测试
6. **fixing** - 自动修复中
7. **completed** - 任务完成
8. **failed** - 任务失败

---

### 作为开发者，我希望在测试失败时启用智能修复

**前置条件**：
- SWE 任务测试失败

**操作步骤**：
1. 查看任务详情，发现测试失败
2. 点击「智能修复」按钮
3. 等待自动修复完成

**预期结果**：
- 系统分析失败原因
- 尝试修复代码
- 重新运行测试
- 显示修复结果

---

### 作为开发者，我希望导出修复后的代码

**前置条件**：
- SWE 任务已完成

**操作步骤**：
1. 在任务详情页点击「导出代码」
2. 选择导出格式（ZIP）
3. 点击下载

**预期结果**：
- 生成预签名下载链接
- 浏览器触发文件下载

---

### 作为管理员，我希望管理仓库缓存

**前置条件**：
- 管理员权限

**操作步骤**：
1. 导航到「仓库缓存」页面
2. 查看已缓存的仓库列表
3. 选择要删除的缓存
4. 点击「删除缓存」

**预期结果**：
- 缓存被删除
- 释放存储空间

## 业务流程图

### 创建 SWE 任务流程

```
开始
  │
  ▼
输入仓库 URL
  │
  ▼
填写 Issue 信息
  │
  ▼
配置测试策略
  │
  ├─► full（运行所有测试）
  ├─► smart（运行受影响的测试）
  └─► skip（跳过测试）
  │
  ▼
选择是否启用自动修复
  │
  ▼
创建任务
  │
  ▼
Worker 克隆仓库
  │
  ▼
构建 issue 索引
  │
  ▼
Agent 执行修复
  │
  ▼
运行测试
  │
  ├─► 成功 ──► 完成
  │
  └─► 失败
      │
      ├─► 启用自动修复 ──► 重新测试
      │
      └─► 不修复 ──► 失败结束
```

## WebSocket 事件

### 订阅地址

```
ws://localhost:8080/api/v1/swenbench/tasks/:id/ws
```

### 消息格式

```typescript
// 进度更新
{
  "event": "swe_progress",
  "data": {
    "task_id": "swe-xxx",
    "phase": "executing",
    "progress": 65,
    "message": "正在分析代码..."
  }
}

// 任务完成
{
  "event": "swe_completed",
  "data": {
    "task_id": "swe-xxx",
    "result": {
      "status": "passed",
      "test_passed": 48,
      "test_total": 50,
      "duration": 180
    }
  }
}

// 任务失败
{
  "event": "swe_failed",
  "data": {
    "task_id": "swe-xxx",
    "error": "测试失败: 2 个测试用例未通过",
    "phase": "testing"
  }
}
```

## 状态说明

### 任务状态 (status)

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| pending | 待执行 | 取消 |
| running | 执行中 | 等待完成/取消 |
| completed | 已完成 | 查看结果、导出 |
| failed | 已失败 | 重试、智能修复 |
| fixing | 修复中 | 等待完成 |

### 阶段 (phase)

| 阶段 | 说明 | 预估耗时 |
|------|------|----------|
| init | 初始化 | < 1s |
| repository | 克隆仓库 | 10s - 5min |
| indexing | 构建索引 | 5s - 1min |
| executing | 执行修复 | 30s - 10min |
| testing | 运行测试 | 10s - 5min |
| fixing | 自动修复 | 30s - 10min |
