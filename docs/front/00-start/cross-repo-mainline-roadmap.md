## Current Mainline Direction

The intended frontend product direction is:

1. make Project Eval, Repair Runs, and Governance the clear mainline
   product path
2. evolve the UI from an engineering console into a workflow product
3. support broader project families and larger projects through clearer UX and
   richer backend read models
4. keep compatibility-only surfaces visibly non-mainline
