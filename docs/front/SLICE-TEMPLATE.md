## 0. 目标

一句话说明本 slice 完成后，用户能在什么页面完成什么操作。

## 1. 为什么先做这个 Slice

说明它和后端主线的关系：

1. 它属于哪个主线阶段。
2. 为什么它比其它页面更应该先做。
3. 它是否是后续 slice 的入口页或上游依赖。

## 8. 验收标准

- [ ] 页面不再依赖 mock 数据。
- [ ] 接口路径、参数、枚举、分页字段与后端实际代码一致。
- [ ] `Authorization` 与 `X-Org-ID` 语义正确。
- [ ] 权限不足、404 隐匿、业务错误能区分展示。
- [ ] loading / empty / error / degraded 状态完整。
- [ ] 长任务刷新机制可工作。
- [ ] `npm run type-check` 通过。
- [ ] `npm run build` 通过。

## 9. 明确不做什么

1. 本 slice 不做什么。
2. 本 slice 不改什么历史页面。
3. 哪些内容留给下一 slice。
